# Inventário de um coworking

## Contexto

O inventário percorre mesas, salas, impressoras e contratos. Relatório patrimonial, cálculo de seguro e exportação fiscal operam sobre os mesmos elementos, enquanto novas operações surgem com frequência.

## Primeira entrega

Gere um relatório patrimonial visitando os itens do coworking.

## Mudança realista

Adicione cálculo de seguro e exportação fiscal sem colocar regras de todos os relatórios dentro de cada tipo de item.

## Critérios de aceitação

- Cada elemento aceita a visita apropriada.
- Uma nova operação não altera a regra das operações existentes.
- O visitante pode usar dados específicos de cada elemento.
- O custo de adicionar um novo tipo de elemento fica explícito.
